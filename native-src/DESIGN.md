# Framelet — native visual direction

Updated 2026-10-02, BRT. Mode: Operate.

The native capture surface is the behavioural authority. The atelier identity extends annotations and finishing while preserving image position, capture speed and the host theme.

- One horizontal toolbar beside the selection. Framelet is a small signature, with a frame-and-sweep symbol.
- UI typography follows the host sans-serif; monospace is reserved for code and dimensions.
- Atelier, Graphite and Botanical are editable five-colour palettes; custom palettes persist.
- The brush uses a smoothed contour, tapered ends, adjustable width and opacity. The pen remains uniform.
- Sketchbook: warm paper, very subtle background grain, almost square corners and a quiet shadow.
- Ink: charcoal backing, clean image, moderate corner radius and a soft shadow.
- Gallery: a light mat, more breathing room and a neutral line around the image.
- Paper texture stays outside the screenshot, preserving text and redacted areas.
- Finishes are optional; Original keeps the image dimensions.
- Control colours and shapes follow Omarchy. Export materials provide the identity.
- The bar symbol is a small image inside the shared BarIconButton slot; it does not change the bar's typography or other widgets.

Launch artwork is a separate Persuade/Read surface, specified in the root docs/launch/BRIEF.md. Its cover illustration is a brand scene; actual interface shots and finish exports demonstrate app behaviour.
