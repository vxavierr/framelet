# Framelet symbol

02/10/2026, BRT. Original artwork for Framelet; MIT, as the application.

Terracotta is the primary version. The cream reverse requires a dark background.
Minimum canvas size: 24 px. Keep the 8-unit margins in the 64-unit viewBox;
at 24 px this provides 3 px of clear space. Do not crop these margins.

Two independent visual reviews passed all seven axes at 4/5; the release gates
accepted both frozen variants. The full review archive is in the development workspace, framelet-brand/. This is a visual/technical review, not trademark clearance.
Run source/brand-v3.mts with Node 24+ to regenerate concepts/. The dark positive
variant produced by the authoring script is experimental and was not released. Study references are not app assets.
