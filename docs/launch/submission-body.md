### Maintainer notes

Framelet is a native screenshot and annotation atelier for Omarchy Quattro. It combines region/window/display capture, inline annotations, a tapered brush, saved five-colour palettes, automatic scrolling capture and the Sketchbook, Ink and Gallery finishes in one app. It is a fork of Omaframe 0.7.4 (MIT); the upstream and Omasnap licence notices are retained.

The repository distributes source. Development dependencies must be installed by the user; the first launch builds the Qt/C++ engine locally. The build script does not download code, install packages or invoke sudo. The README covers installation, removal, optional OCR/recording/code tools and current limits. Super+C/S forwarding is an explicit opt-in Lua example; the plugin does not rewrite personal bindings.

The root preview is the launch cover. Interface screenshots and finish examples in the README are actual native app captures/exports on fictional sample content. The botanical cover artwork was generated with OpenAI ImageGen; the original Framelet symbol and bundled OFL font licences are documented. The plugin ID was checked against the current registry, including retired IDs, and is not present.
