# Framelet 0.3.0

An atelier for screenshots on Omarchy. Select a region, annotate the frozen capture, choose a finish, then copy or save from the same overlay.

- Inline arrows, text, shapes, highlights, redaction and a smooth tapered brush.
- Atelier, Graphite and Botanical palettes, plus saved custom palettes.
- Sketchbook, Ink and Gallery finishes; custom framing and reusable looks.
- Automatic scrolling capture, local OCR, code cards, composition and PNG/JPEG export.
- A single native plugin with a compact bar symbol.

This release is distributed as source. Install the dependencies in the [README](https://github.com/vxavierr/framelet#install); the first launch builds the Qt engine locally. The build does not download code or install system packages. Print and Super+C/S are configured with the included opt-in Lua example.

Tested on x86_64, Omarchy 4.0.4 and Qt 6.11.2. Scrolling depends on the page's content, and the capture controls currently include Portuguese labels. See the README for the full setup and current limits.

Based on Omaframe 0.7.4 under MIT. The original upstream notices, Omasnap notice and bundled font licences are retained. The botanical launch artwork was generated with OpenAI ImageGen; the interface and finish examples are real app captures and exports.
